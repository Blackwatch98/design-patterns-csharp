# Design Patterns in C#

A personal repository for learning, revising, and practicing design patterns in C#.

This project is organized by pattern categories and focuses on clear, practical examples.  
Each pattern is treated as a small learning module with:

- a short explanation
- a naive solution
- a pattern-based solution
- tests
- a simple demo

## Goals

- build a solid understanding of design patterns
- compare naive and improved implementations
- keep reusable examples in one place
- create a practical reference for future revision
